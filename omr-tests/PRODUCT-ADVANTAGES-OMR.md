# Преимущества продукта: Compath OMR / Pro+AI

Копирайт для shop.compath.ee, Partner page, rehearsal.compath.ee (EN/ET — перевести при публикации). Источник: WP-22 §3.18.0, WP-23.

## Bullet list (RU)

* **Распознавание нот (OMR)** — загрузка PDF/скана, на выходе MusicXML / `.mxl` для MuseScore и веб-плееров.
* **Нотная грамота на лету** — сервер правит гипотезы сканера по правилам тональности (например, при си♭ в ключе не бывает си♯; в соль миноре ожидается фа♯ как вводный тон).
* **Память правок** — подтверждённые исправления запоминаются и ускоряют следующие прогоны той же партитуры.
* **Контроль качества** — несколько слоёв проверки спорных мест + показатель уверенности в ответе API.
* **Без лишних расходов на LLM** — грамматика считается на CPU; нейросеть — только по желанию для сложных случаев.
* **Знакомый биллинг** — подписка SureCart, license key и активация, как у Choir Rehearsal Pro; для приложений — Partner API без обязательного WordPress.

## What we do **not** sell

Отдельный публичный бесплатный «учебник гармонии как JSON API для всех» — не продукт. Правила грамоты входят в лицензированный OMR / Pro+AI.

## Short EN blurb

Compath turns choir score scans into MusicXML — then applies live music-literacy rules and learned corrections so pitches make sense in the key, not just as OCR guesses. Same SureCart licensing as Pro; Partner API for third-party apps.
