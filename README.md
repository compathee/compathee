## n8n workflows

Workflow backups and deployable n8n JSON files are stored in
[`workflows/`](workflows/). **DBT Accountant assistant** Telegram uploads now
auto-extract Word/DOCX into the `--- Extracted attachment ---` block and can
fill cells in the original file and send it back (see
[`workflows/dbt-accountant-docx.md`](workflows/dbt-accountant-docx.md)).
