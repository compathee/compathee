Choir Rehearsal

A private rehearsal library for choirs: songs, voice tracks, PDF scores, and easy listening on phone or desktop.

Download latest release Order & subscribe

Overview

Choir Rehearsal helps choir members learn new pieces by voice part. Editors upload PDF scores and audio for each voice (or record from a phone). Singers visit /rehearsal/, pick a song, and listen to their part.

  • Song list on your choir website
  • PDF viewer with page navigation
  • Voice tracks: bass, tenor, alto, soprano, and more
  • Microphone recording in the admin
  • Sticky player at the bottom of the screen
  • Login-only access (optional)
  • Roles: editors manage, singers listen
  • WordPress-native plugin updates

Requirements: WordPress 6.4+, PHP 8.0+. Owner and developer: Compath OÜ, Tallinn, Estonia. First customer — Cappella Veneta.

How to order

  1. Email order@compath.ee with subject “Choir Rehearsal” — include your choir name and website URL.
  2. We send an invoice; after payment you receive a license key (Pro) or we schedule installation.
  3. Enter the key in Choir Rehearsal → Settings → License key — updates appear under Plugins automatically.

Discounts available for non-profit choirs and educational projects — ask when ordering.

Installation

Self-service (Community)

  1. Download choir-rehearsal.zip from GitHub Releases.
  2. In WordPress: Plugins → Add New → Upload Plugin — select the zip and activate.
  3. The plugin creates a /rehearsal/ page with the [choir_rehearsal] shortcode.
  4. Add a song: Choir Rehearsal → Add Song — title, PDF, voice tracks.
  5. Give singers WordPress accounts (Subscriber role). Editors get Editor or Administrator.

Updates

  • Pro: license key in settings — WordPress shows updates automatically.
  • Community: upload a new zip, or set Update JSON URL from the repository and click “Check for updates now” in settings.
  • Installed version is shown in Choir Rehearsal → Settings.

User roles

  • Subscriber (Singer) — browse songs, listen, view PDF.
  • Editor / Administrator — add and edit songs, record voice tracks.
