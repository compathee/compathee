Choir Rehearsal

Закрытая библиотека репетиций для хора: песни, голосовые дорожки, PDF-ноты и удобное прослушивание с телефона или компьютера.

Описание

Choir Rehearsal помогает хору учить новые произведения по голосам. Редакторы загружают PDF с нотами и аудио каждого голоса (или записывают прямо с телефона). Певцы заходят на страницу /rehearsal/, выбирают песню и слушают свою партию.

  • Список песен на сайте хора
  • PDF-просмотр с листанием страниц
  • Голосовые дорожки: bass, tenor, alto, soprano и др.
  • Запись голоса с микрофона в админке
  • Липкий плеер внизу экрана
  • Доступ только для залогиненных пользователей
  • Роли: редакторы управляют, певцы слушают
  • Обновления через WordPress, как у обычного плагина

Требования: WordPress 6.4+, PHP 8.0+. Владелец и разработчик: Compath OÜ, Tallinn, Estonia. Первый заказчик — Cappella Veneta.

Установка

Самостоятельно (Community)

  1. Скачайте choir-rehearsal.zip с GitHub Releases.
  2. В WordPress: Плагины → Добавить → Загрузить плагин — выберите zip-архив и активируйте.
  3. Плагин создаст страницу /rehearsal/ со шорткодом [choir_rehearsal].
  4. Добавьте песню: Choir Rehearsal → Add Song — название, PDF, голосовые дорожки.
  5. Выдайте певцам учётные записи WordPress (роль Subscriber). Редакторам — Editor или Administrator.

Обновления

  • Pro: ключ лицензии в настройках — WordPress покажет обновления автоматически.
  • Community: скачайте новый zip и загрузите поверх, или укажите Update JSON URL из репозитория и нажмите «Check for updates now» в настройках.
  • Текущая версия отображается в Choir Rehearsal → Settings.

Роли пользователей

  • Subscriber (Певец) — просмотр списка, прослушивание, PDF.
  • Editor / Administrator — добавление и редактирование песен, запись голосов.
