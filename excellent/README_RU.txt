Excellent Books — заполнение Eelarve из месячных отчетов
=======================================================

Это основной сценарий для Windows-клиента. Скрипт берет месячные
экспорты Kasumiaruanne (колонки объектов HK_*, KÜ_*, KV_* и т.п.)
и записывает суммы в книгу Eelarve: в нужный блок konto и в колонку
выбранного месяца. Старое «сплющивание» колонок в плоскую таблицу
больше не является основным назначением клиента.


Что внутри
----------

- run_eelarve_fill.bat
  Основной запуск двойным кликом.

- run_combine_excellent_reports.bat
  Тот же запуск (оставлен, чтобы привычный файл открывал новый сценарий).

- run_combine_excellent_reports_legacy.bat
  Старый unpivot-комбайнер (плоская таблица). Нужен только если
  специально нужен прежний формат.

- requirements.txt
  Python-зависимости (openpyxl).

- scripts/eelarve_fill.py
  Основной Python-скрипт заполнения Eelarve.

- scripts/combine_excellent_reports.py
  Устаревший скрипт unpivot.

- input/
  Необязательная папка для исходных файлов. Диалог может открыться
  здесь, но файлы можно выбрать из любой папки.

- output/
  Папка для новой книги, если вы не выбрали существующий Eelarve.
  Имя по умолчанию: output\Eelarve_<год>.xlsx


Как установить клиенту
----------------------

Скопируйте всю эту папку в:

  C:\temp\excellent

Итоговая структура должна быть:

  C:\temp\excellent\run_eelarve_fill.bat
  C:\temp\excellent\run_combine_excellent_reports.bat
  C:\temp\excellent\requirements.txt
  C:\temp\excellent\scripts\eelarve_fill.py
  C:\temp\excellent\input\
  C:\temp\excellent\output\


Как запускать
-------------

1. Убедитесь, что установлен Python 3.
2. Откройте:

   C:\temp\excellent\run_eelarve_fill.bat

3. Скрипт создаст папки input\ и output\, если их еще нет, и спросит:

   a) Существующий файл Eelarve (.xlsx).
      Если нажать Cancel / оставить путь пустым — будет создана НОВАЯ
      простая книга output\Eelarve_<текущий_год>.xlsx.
      Сложный образец-шаблон не копируется. Файл, который вы не
      выбирали, скрипт не меняет.

   b) Один или несколько месячных исходных .xlsx (лист Kasumiaruanne).
      Можно выбрать из любой папки, не только из input\.

   c) Для каждого исходного файла — месяц (Jaanuar … Detsember).

   d) Необязательный справочник объектов .csv/.xlsx
      (колонки object_code и object_name). Cancel = работать без него.

4. После успеха появится окно с полным путем к сохраненному файлу и
   статистикой: сколько ячеек записано, сколько строк объектов
   добавлено, сколько блоков konto не было в исходном Eelarve.
   Тот же текст печатается в консоли. В процессе работы консоль
   показывает этапы на русском и процент выполнения (не каждую
   строку данных). Файл сохраняется сразу после создания заголовка
   и после каждого исходного месяца, поэтому размер на диске растёт
   до конца работы. Если файл занят (открыт в Excel), скрипт
   напишет какой именно, и спросит: продолжить (пропустить
   источник / повторить сохранение) или прервать.

   Остановка: в окне консоли нажмите Ctrl+C — работа прервётся с
   понятным сообщением. Незакрытый Excel может блокировать сохранение.

5. Если отменить выбор исходных файлов или произойдет ошибка, появится
   понятное сообщение, программа завершится с ошибкой.


Как устроены исходные файлы
---------------------------

Лист Kasumiaruanne:

  колонка A — номер konto: только чистое 4-значное число
  (3241, 3200, 4205; Excel 3241.0 тоже подходит);
  колонка B — описание;
  колонки C и далее — коды объектов (HK_*, KÜ_*, KV_* …) с суммами
  за ОДИН месяц.

Колонка Periood и строки без чистого 4-значного konto в колонке A
(пустые, заголовки разделов, Kokku…, текст с цифрами, 3/5/6 цифр,
несколько номеров через запятую) игнорируются целиком — их суммы
не берутся.
Суммы вида «2 848,00» понимаются как числа.


Как заполняется Eelarve
-----------------------

Для каждой тройки (konto, код объекта, сумма):

1. Находится блок этого konto. Если в одной ячейке заголовка несколько
   номеров через запятую (например 3150, 3160, 3400), каждый номер
   считается своим konto, но указывает на один общий блок. Объекты
   ищутся и добавляются только внутри блока (одно и то же имя объекта
   может быть и в доходах, и в расходах).
2. Строка объекта ищется сначала по коду/имени, затем по описанию
   из CSV.
3. Если строка найдена — число записывается в колонку выбранного месяца.
4. Если не найдена — в блок добавляется новая строка объекта
   (подпись из CSV, если есть) и в неё пишется сумма.
5. У каждого konto из источников должен появиться полный список
   объектов, у которых есть суммы.

Не трогается:

- разделы/konto, которых нет в исходных файлах (например общие
  расходы без объектов);
- строки итогов KOKKU / Kokku (их значения не перезаписываются).

Итоги считаются формулами Excel (SUM). При вставке строк соседние
диапазоны SUM расширяются. Новая книга сразу содержит формулы SUM,
чтобы итоги обновились после открытия в Excel.

Если в существующем Eelarve konto есть одной строкой без дочерних
объектов, недостающие объекты добавляются под этой строкой.


Справочник объектов (необязательно)
-----------------------------------

  object_code,object_name
  HK_NOMME,Nomme LOV
  HK_KESKLINN,Kesklinn LOV

Без справочника скрипт всё равно работает: поиск и новые строки
идут по коду объекта.
